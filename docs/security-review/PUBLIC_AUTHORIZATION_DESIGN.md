# PUBLIC 授权证据：待评审的下一轮设计

**状态：设计提案，未实现，未获独立评审决定。**
不得将本页当成来源真值、自动公开分类器或恢复 pilot/保留集的依据。
本页对应 [代码审查](README.md) 的明确误标边界；R3 与所有既有失败记录保持冻结。

## 1. 目标与无法消除的假设

将“信任配置里的一个 PUBLIC 字段”收窄为“信任一个有明确授权人、内容版本、投影和接收者的公开授权记录”。
这个设计能检查记录的身份、范围、一致性、期限和吊销状态，不能自行知道内容在语义上是否敏感。
如果具备授权权力的人作出错误判定，系统仍可能泄露；需要独立真人真值、任务所有者授权及相应误标测量。

## 2. 候选记录契约

| 字段 | 必须绑定的对象 | 不应推导的能力 |
|---|---|---|
| `grant_id` / `issuer_id` / `key_id` | 有权授予该来源/投影权限的身份与版本 | 有签名不代表签名者拥有公开权力 |
| `source_category` / `reference_id` | 原始来源的受控标识 | 相同路径或工具名不代表内容未改变 |
| `source_version` / `content_digest` | 读取到的当前内容，或批准工具的可验证版本 | 内容哈希不证明语义正确；敏感原文不写入日志 |
| `projection` | 叶级字段路径或严格字符范围及对应数据 schema | 文本位置相同不代表语义含义相同；结构漂移须重审 |
| `sink` / `reader` / `purpose` | 精确接收目标、允许的读者与用途 | 域名白名单不代表该域名内所有收件人与用途均获准 |
| `issued_at` / `expires_at` / `revocation_version` | 当前有效且未吊销的记录 | 过期或未知吊销状态不能默认为有效 |
| `decision` / `review_evidence_id` | 明确 PUBLIC 判定及可独立审计的依据 | `UNCERTAIN`、争议或机器评分不能投影成 PUBLIC |

数据类型、规范化序列化、签名算法、密钥轮换、吊销查询故障策略和时钟来源须在实现前写成版本化契约。
记录中不得包含原始敏感值；外部展示的内容摘要也须考虑低熵秘密的字典反推风险。

## 3. 候选接入位置

1. 在可信文件/工具适配器完成读取后，对同一份实际读取数据做版本与授权核对，避免用后续再次读取的数据代替。
2. 在 `_ingress` 创建标签前判定当前声明是否有合法、有效、范围匹配的授权证据。缺少证据的旧 PUBLIC 是否统一成为 UNKNOWN，以及兼容迁移方式，属于待审策略。
3. 精细化传播保留已批准投影的依赖；转换、结构漂移或拼接扩大范围时不得沿用不再匹配的授权。
4. sink 前同时核对当前活跃依赖、目标/读者/用途与吊销状态，再执行现有内容/污点与访问策略检查。
5. 记录脱敏的授权编号、判定和拒绝原因；审计不能把 `ALLOW` 当作接收端已送达或任务已完成。

授权核对与来源分类应为独立模块。现有会话完整性仍可绑定授权结果，但不能代替授权人的语义判定。
统一 REQUIRE_REVIEW 或 BLOCK 可能增加误阻断，安全与任务效用必须按事前契约共同评估。

## 4. 实现前应冻结的验收条件

以下是未来开发单元控制的候选清单，尚未执行，不是新研究数据或通过结果。

| 条件 | 候选预期 | 必须保留的对照 |
|---|---|---|
| 无授权的明确 PUBLIC、未知授权人、签名无效 | 在受保护 sink 前拒绝/请求审查 | 有合法授权的正常公开任务可发送 |
| 来源内容变更而 reference 未变、授权过期或已吊销 | 不沿用旧 PUBLIC 许可 | 同版本未过期的匹配许可仍有效 |
| 字段移动、schema 改变、字符范围扩张、合并未批准字段 | 拒绝过宽或无法核对的投影 | 原精确投影不被无关敏感字段污染 |
| 跨会话/跨来源重放、目标/读者/用途不符 | 拒绝不匹配授权 | 当前任务的匹配授权正常工作 |
| 吊销服务不可用、时钟不可靠、审计写入失败 | 按冻结故障策略拒绝/审查 | 失败来源单独归因，不计作敏感检测成功 |
| 有权授权人对敏感内容作出语义错误 PUBLIC 判定 | 保留为可发生的失败边界 | 不用签名检查把该失败改记为 HELD |

研究层面另外需要独立盲化真人标注、预定抽样/缺失规则和外部任务契约。
开发单元控制不等于独立图，不能加入 GHO-1/H5 分母或扩大现有预算。

## 5. 当前决策

本轮实现只包含可选 Dots 传输加固；上述 PUBLIC 授权设计保持待评审。
尚未决定授权人角色、记录格式、旧配置迁移或策略切换，也没有修改 runtime、R4 readiness、估计器、阈值或任何研究执行权限。
