# 未来候选验证设计（未执行、未获预算授权）

不启动pilot/保留材料。下一方法版本需先完成独立定理/假设审查及阈值任务价值依据，
选择估计器和声明族后，再冻结响应模型、种子、观测机制、预算及分析接口。
这里列验收问题，不是已执行或已预注册的确认性协议。

## 三层验证与停止规则

1. 结构界：为各条件给出最大可能下界/最小可能上界及全分母缺失界。
   若目标预算的任一必要条件不可达，标为结构不适用，不靠增加同配置MC次数“救功效”。
   界可达后还要检查任务契约是否允许构造该输入，不能用任意极值冒充真实响应。
2. 完整向量功效：所有六点安全曲线、六点TCR差异、六点绝对TCR、一次E0、全分母/观测门禁。
   在事前定义的合理效应范围与不利控制下测联合确认，不以单点曲线或只计eligible替代。
3. 覆盖/错误确认：分别记录13项同时覆盖和完整H5错误确认率，不混成一个指标。
   满足/不满足H5由事先解析/高精度真值定义，不能根据接收结果或新估计器的判定改变真值。

全拒绝、无安全改善和边界H5原假设控制必须保留。功效不足和错误率不足分别报告，
不能因二者之一好看而宣称候选有效。失败不删；任何修改产生公开新方法版本。

## 有限样本校准必须覆盖的依赖和缺失

图内共享全局故障、策略配对、率点嵌套/相关、固定家族依赖继续保留。
IID图条件与跨图共享块条件单独标识；IID定理不得在共享块条件下计为已保证。
跨图共同潜变量至少一种能让表面图数大于有效独立块数，用于检测错误率失控。
缺失含完整、值无关和与泄露/完成相关的机制，E0只记录一次。
缺失95%门禁失败保留UNRUN，联合统计仍保留计划分母和最坏界。

定理适用范围外的条件可作为反例/鲁棒性检查；若候选对此没有保证，必须明确标注。
新候选不能用开发结果再挑“易通过”的效应或图预算，仍称它为独立保留验证。

## 校准精度、方法选择与人类门禁

不能沿用每格200次作为强联合错误率保证；零/200的二项不确定性仍非零。
MC次数应由要分辨的错误率、功效精度及跨条件审核规则确定，先写下容忍区间和分配方式。
这些数值目前没有独立任务价值授权，所以本页不凭作者猜测替其设定“通过”阈值。
不因新的区间更窄或开发确认更多而选胜者；选择理由应来自估计对象、假设和可审查定理。
开发校准可用于否定候选；确认性材料须在方法与预算独立审查后收集并冻结。

阈值所有者需论证5%改善/非劣、80%最低完成率和2%等效界所对应的应用损失与最低任务价值。
真实两人盲化标注、第三人仲裁和TA-2独立审计必须真实执行，哈希不能替代语义授权。
FIDES/APPA配对适配、真实Agent、多轮注入与外部攻击属于独立验证线，不由解析界放行。
