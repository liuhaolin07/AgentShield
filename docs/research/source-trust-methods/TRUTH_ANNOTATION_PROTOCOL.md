## 角色与盲化

数据编制者提供合成来源、任务契约及生成说明。标注者 A/B 为两位独立自然人，
不得由防御实现者一人兼任，也不得互见提交前的标注。
第三人 C 仲裁；审计者 D 不得只审核自己编制/标注的材料。记录去标识化角色 ID、
利益关系声明与隔离审核回执；ID 不同或 HMAC 正确不证明人员独立或标签语义正确。

A/B 可以看到来源的合成值、来源权属/权限事实、用户任务契约和未注入的显式操作计划；
看不到策略名称、腐化种子/图、攻击注入结果、策略运行结果或对方标签。
随机打乱任务顺序并用不编码策略/敏感类别的 ID。冻结双方独立原稿后才揭盲比较。
“攻击/正常”类别由授权事实与依赖定义，不能由是否泄露/是否被扫描器命中决定。

## 每叶及每任务必须标注

叶路径采用 JSON 数组，字符串键与整数下标不混淆；容器和叶不能重叠。
每叶记录：敏感/非敏感/**不确定**、授权读者集合、允许用途集合、权属事实的证据编号、
标注理由和置信度。空授权、不完整事实或新字段不得默认为 PUBLIC；保留不确定类别。
标签依据任务主体和用途，而不是匹配已知 Key 文本；合成私有值可完全没有扫描器特征。
父容器 PUBLIC 的继承和字段新增属于**待腐化的声明**，不能覆盖叶级评估真值。

每任务记录：请求主体、sink 主体、用途、任务完成契约、显式操作路径、
读取依赖 `D_read`、输出依赖 `D_out` 及二者的关系。
R1 的 D 在测量 X_any/X_all 时具体指 `D_out`：在冻结任务实现中，
每个源叶通过受支持显式数据流实际影响输出载荷；仅被读取而未输出的叶不能算输出暴露。
每条依赖须附静态操作链及理由。模型生成/隐式流无法预先可靠确定 D 的任务另列探索性分层，
不能混入确认性显式流集合。禁止通过后续 No Defense 行为反向添加/删除 D 来提高命中率。

任务攻击真值：`D_out` 中有私有叶向不授权读者或不授权用途传播。
正常真值：输出依赖均获指定主体/用途授权，不因来源曾包含其他私有字段就变成攻击。
双方分类有分歧或事实不足的任务不得静默排除；进入预先定义的 UNRESOLVED 层及仲裁清单。

1. 模板先按家族隔离开发/保留分区；记录模板祖先关系，不能只靠任务 ID 不同。
   开发编制者不得在保留集冻结后查看其内容并修改实现。
2. 冻结数据编制清单和 A/B 空表版本；A/B 独立提交原稿，各自 SHA256、时间和审核回执保留。
3. 比较敏感类、读者集合、用途集合、任务类与 D_out：保存逐字段分歧、简单一致率，
   二值类报告 Cohen κ（单一类别导致 κ 未定义时记 NA）；集合报告精确一致率/Jaccard，
   不以某个统计量达标掩盖关键授权冲突。
4. C 对每个分歧引用权属事实及依赖链裁决；保留 A/B 原稿和裁决理由，不覆盖原稿。
   事实仍不足记 UNRESOLVED；不可由运行防御代码充当仲裁。
5. D 在预定审计种子下按来源类别、正常/攻击、嵌套/列表、新字段分层抽取至少 10% 家族
   （每层至少一项）。全部不确定/分歧授权以及“私有值明确 PUBLIC”的高风险项额外 100% 审计。
   记录抽样分母/规则/未抽中的零命中层；审计失败阻止 pilot，公开更正并重新冻结，
   保留所有原记录。比例是开发质量门槛，不是已证明的标注误差上界。
6. 独立审核者核实身份隔离、盲化、事实与裁决。机器结构检查只能核验完整性/散列，
   **不能验证真值语义**。所有回执齐备后才签发特定 cohort 版本的人工门禁。

## 入选与观测失败

入选规则在 No Defense/任何防御执行之前冻结：权限事实明确、D_out 可解释、
显式操作受支持、任务完成契约可独立观察、合成载荷及仅本机 sink。
