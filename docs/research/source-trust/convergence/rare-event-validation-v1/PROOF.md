# 加权簇有限样本候选：条件性覆盖推导

状态：作者推导，待独立审查；尚未应用到协议。

固定一个统计量j。合格家族集合、模板簇成员、簇大小、种子权重及H3合格掩码必须在观察结果前固定。
共有n_j个合格家族；每个家族的已完成统计组件Y_ij属于事先指定的[a_j,b_j]。
H1/H2/H3及H5差值、差值AUC的范围为[-1,1]，绝对TCR为[0,1]。
同一家族内的种子、策略、任务和条件可以任意相关；同簇内家族也可以任意相关。
唯一的概率独立性要求是不同模板簇的完整随机向量相互独立，条件为上述固定设计。
**簇名称、作者不同或模板不同本身都不建立该独立性。**

令簇c中合格家族数为n_cj，w_cj=n_cj/n_j，簇组件为这些家族组件的平均值Z_cj。
因此Z_cj∈[a_j,b_j]，全体家族等权的估计量是：

```text
T_j = Σ_c w_cj Z_cj = (Σ_i Y_ij) / n_j
μ_j = E[T_j | 固定设计]
```

这里的估计目标是固定设计下的期望；若论文需要一个不同的超总体目标，必须另外规定采样模型并重新论证。
簇大小不等时直接对簇均值等权会改变T_j和μ_j。

每个独立项w_cj Z_cj的范围长度为w_cj(b_j−a_j)。Hoeffding不等式给出：

```text
P(|T_j − μ_j| ≥ ε_j | 固定设计)
  ≤ 2 exp(−2 ε_j² / [(b_j−a_j)² Σ_c w_cj²])

ε_j = (b_j−a_j) sqrt(log(2m/α) Σ_c w_cj² / 2)
m=17, α=.05
```

代入得到每个统计量失败概率至多α/m；对17项使用union bound，无需它们之间独立，
即可得到同时覆盖概率至少1−α=.95。区间为：

```text
[max(a_j,T_j−ε_j), min(b_j,T_j+ε_j)]
```

簇数不等于有效簇数。后者为`1/Σw_cj²`；向同一簇复制相同家族不会增加有效独立信息。
单簇时该界通常退回整个参数域，仍不提供确认性成功。

## 缺失界

假设观察链给出的每个家族组件界为L_ij≤Y_ij≤U_ij；这些界必须确实包含所有合法完成值。
原线性统计配方按系数正负，将未知二元端点替换为0/1，产生这样的逐家族界。
记L_j=mean(L_ij)，U_j=mean(U_ij)。逐点恒有L_j≤T_j≤U_j，因此：

```text
μ_j ∈ [T_j−ε_j,T_j+ε_j]
  ⇒ μ_j ∈ [L_j−ε_j,U_j+ε_j]
```

不论缺失机制是否随机，都能按此扩展区间；保证依赖完整潜在组件的独立簇和固定设计假设。
不允许按送达结果、可观察性、策略决策或错误状态选择合格家族/权重。
95%观测覆盖门禁仍须另行验证；数学区间不能替代独立接收/执行证据。
空H3合格集合的估计目标未定义，返回null，不把它计作零。

## 适用性与精度

这是充分保守的有限样本参照，不依赖观察到事件或非零经验方差。
它并不证明真实材料独立、抽样正确或当前样本量的功效足够。
若共享模型状态、共同作者生成流程或隐藏模板造成跨簇依赖，该证明的前提可能失效。

对60个等权独立簇、[0,1]组件，半径为`sqrt(log(680)/120)≈.233`。
即使观察值全为1，下界也只有约.767，因此本候选无法在现有60家族预算内满足原绝对TCR≥.80的数值条件。
这是该保守候选的精度成本，不是扩大正式预算或修改H5角色的依据。

Clopper–Pearson诊断只针对一个独立同分布Bernoulli事件率的二项计数。
分别反演左右二项尾部，每尾α/(2×17)，得到单参数覆盖至少1−α/17的精确区间；
代码用浮点求根并向外扩展1e-12，尚未经区间算术认证。
该结论不能直接用于种子平均、配对差值、AUC或不等家族权重。
