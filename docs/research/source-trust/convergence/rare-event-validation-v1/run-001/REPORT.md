加权簇Hoeffding候选在复现的700个固定数学数据集中全部覆盖已知真值。该方法的有限样本保证依赖明确的独立簇与固定权重/合格集合假设；真实材料尚未验证这些假设。原bootstrap结果按摘要读取，未重新执行重采样。候选尚未应用到协议。

## 能解决什么，代价是什么

30簇零事件时，单纯重采样只能复现零；加权Hoeffding对范围[0,1]给出半径约0.330，对配对差值范围[-1,1]给出半径约0.659。区间不会因未观察到事件收缩为零。

代价是区间很宽：60个等权独立簇即使绝对TCR全部为1，下界也只有0.767，达不到原.80数值门槛。这说明该候选的精度限制；正式预算仍保持60家族/每split，不据此扩样。

受限二项诊断使用Clopper–Pearson尾概率反演：已知iid二元簇事件、30簇零事件时，
区间为[0,0.195]。27组(n,p)穷举核对均报告在JSON中；它仅适用于真实二元计数，不能直接替代多种子平均、配对差值、AUC或不等家族权重。

700次覆盖100%是模拟结果；有限样本依据是[条件性证明](../PROOF.md)，不是通过模拟推导的普遍保证。相同模板或共同生成流程可能使不同簇相关，簇标签本身不能证明独立。

## 冻结前的收敛决定

1. 保留原bootstrap失效证据；Hoeffding作为可复核的保守参照，CP作为受限二元诊断。两个候选均未自动替换协议。
2. 先明确实际材料的采样模型、独立簇与估计目标，再评估与该数据结构相容、精度足够的区间方法；不得按holdout结果选择。
3. 仍需独立证明/实现审查、账本端点适配、联合缺失验证与开发pilot功效分析。G09/G10保持未完成。
