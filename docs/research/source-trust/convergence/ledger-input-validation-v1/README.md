## 采样与估计目标

当前有依据的目标是固定作者夹具与固定条件的描述均值。材料来自作者便利合成，共享生成配方及identity指令。
这份声明明确记录`outcomes_seen_before_declaration=true`，不能倒填成执行前注册。
`sampling_contract.py`校验当前草案的来源/计划/账本摘要，不能证明材料真实、随机取样或簇间独立。

未来研究的以下六项保持null，直到有具体可查的材料和设计记录：

| 字段 | 完成标准 |
|---|---|
| estimand | 写清有限材料集、随机注入分布或超总体中的哪一个量，并固定家族/种子权重；不得混用目标 |
| sampling_frame_ref | 给出符合首面板契约的候选来源范围、纳入排除规则、版本及可查引用 |
| selection_mechanism | 固定来源/模板如何选入；便利取样不能标成概率样本 |
| sampling_randomness_ref | 如使用随机取样，记录抽签机制、种子/外部随机源及冻结时间；非随机方式须在修订契约中明确其适用界限 |
| cluster_independence_evidence_ref | 给出作者、模板、生成器、共享数据及状态的派生审计，解释独立性假设为何可辩护 |
| pre_outcome_design_commitment_sha256 | 在研究结果可见之前固定以上设计与成员/权重/合格集合；已有结果的声明不能补签成事前承诺 |

共享lineage不得仅靠更名拆成独立簇。该v1格式只验证现有候选草案；真实研究契约须另行修订并审查，
不能在本文件填上true或虚构引用就取得实验许可。独立语义复核及主接收清单仍未完成。

## 端点适配检查与范围

`ledger_endpoints.py`接受development单字段identity契约、源字节、计划和既有观测对象。
先校验材料和图选择，再校验图/标签/任务/策略绑定，最后按固定控制先行顺序核验完整账本和摘要链。
E3与匹配随机图、逐家族预算及执行前D由分离图校验器复核；H3掩码从E3图中k>0重建。

以下情况拒绝输入：缺失/重复/乱序账本记录、未计划家族或策略、重复配置、重新摘要后的错误图选择、
来源/投影摘要漂移、错误回执类型、holdout混入或不支持的材料变换。
显式的失败行可以保留：未观测行产生未知端点，不能当阻断；已知攻击送达在评分异常后仍保留ASR=1；
有审计支持的工具错误对正常任务记TCR=0/FPR=0，对攻击保持ASR未知且无防御credit。

完整81配置和60开发家族、所需端点及H3掩码未全部具备时，不构建首轮统计输入；
具备这些结构也不代表独立性、功效或注册通过。当前完整研究账本、holdout路径、真实模型、
多叶/复杂变换及其他外发路径均尚未验证。摘要一致性也不能证明账本由可信记录器诚实产生。
