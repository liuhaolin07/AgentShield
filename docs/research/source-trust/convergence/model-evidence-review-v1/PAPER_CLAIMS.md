# 当前可用表述与最小证据闭环

## 可直接写入实现验证部分

> 我们在一个来源绑定、字段选择受限且接收地址固定的合成工具工作流中，接入Dots与DeepSeek进行开发验证。每个模型执行8条轨迹，覆盖文件及批准工具两种来源、敏感外发与正常任务，以及无防御对照和precision策略。在每个模型的两条敏感任务中，无防御对照均产生实际送达，precision均在外发执行前阻断；两条正常任务在两种策略下均完成。工具结果成功回传模型。本实验仅验证该工作流的接口与运行时执行一致性。

必须紧接着披露：两模型复用2个作者合成家族、同一模板，字段值不进入模型上下文；
非法或偏离任务的操作由框架拒绝，不能计为AgentShield阻断。第二模型的设计与执行
发生在首个模型结果已知之后。未做总体区间估计、能力优劣比较或因果推断。

引用[Dots报告](../dots-tool-study-v1/REPORT.md)、[DeepSeek报告](../deepseek-tool-study-v1/REPORT.md)
及[统一只读审查](audit.json)。这段内容属于实现验证，不可放入H1–H5确认性结果。

## 尚不能写成结果

| 表述 | 缺口 |
| --- | --- |
| 模型能力增强也不能突破权限 | 未操纵或测量能力变化；工具范围由宿主限定 |
| 敏感信息不存在其他外发路径 | 未覆盖任意网络、子进程、隐式流或模型改写 |
| 对来源标签错误稳健 | 本轮真实模型工作流仅E0；工程错标演练不替代独立研究证据 |
| 两模型独立复现了结论 | 复用材料、作者、环境及执行器，第三方未参与 |
| H1–H5已被支持 | 未完成相应条件、材料、统计门禁或注册 |
| 模型行为可从存档独立重评分 | 原始模型响应未保存，只有摘要与派生记录 |

H1–H3、H5的证据缺口仍属于当前协议待完成工作；不能为了宣称已完成而全部移至future work。
H4继续按原协议保持条件性阶段，机制选择未完成。任意外发路径完整覆盖、隐式流、
跨机制FIDES/APPA适配若不纳入当前研究路线，应明确写成未覆盖范围或future work。
