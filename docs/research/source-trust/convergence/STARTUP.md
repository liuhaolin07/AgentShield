## 本轮实际完成

1. `material_adapter.py` 核对开发材料原始字节 SHA-256、每叶值摘要及完整叶集合；
   提供只读 CLI，不执行材料。拒绝未登记家族、未知叶、错误摘要和不支持的任务。
2. 声明适配器只接收源正文、来源类别和 defense_labels 投影，不接收真值、任务类别、
   D、暴露或完整错标图。编排端先校验计划绑定，再将每家族声明转换为冻结运行时的
   SourceRegistry。原始源字节与投影 source_version 必须匹配。
3. 合成集成探针走真实文件读取/工具返回、get_item、SourceTrustRuntime.send 和
   127.0.0.1 接收端。独立接收端到达记录与发送回执、执行器进入次数、审计记录交叉核对。
   同进程观察器仍属于可信测试设施，不是第三方独立执行者或进程隔离证明。
4. 观测校验区分 OBSERVED_DELIVERY、OBSERVED_BLOCK、INCOMPLETE。源未就绪、审计
   不一致、发送失败、缺回执、计数冲突不能取得阻断信用。即使证据不完整，已经观察到
   的目标内容送达仍保留 observed_delivery=true，不能被错误或拒绝声明抹去。

测试矩阵有两个人工合成家族（文件/工具各一），两个身份输出任务、三策略、三个条件
（E0、SP p=1、PS p=1）：每次完整测试运行 36 个探针，16 次实际本机 HTTP 送达。
另有只读材料与观测反例检查。这些次数不是新研究样本、pilot 行或正式结果。
测试结果和运行次数见 [验证记录](verification.json)。未发起模型请求或外部网络调用。

## 首个适配子集与材料接收方式

支持平坦 JSON 对象，20–31 个非空键的字符串叶、每任务一个依赖叶、identity 输出。
31 上限来自冻结实现最多 32 个来源标签，根结构占一个；不截断输入来绕过预算。
JSON Pointer 的 ~0/~1 正确解码为字面键。嵌套对象、非字符串值、多依赖或其他变换
当前明确拒绝；这是适配器限制，不把原协议“至少20叶”修改为新的总体样本定义。
需要这些材料时必须先补适配，不能悄悄删除不支持的家族。

本子集的材料包约定是一个 UTF-8 JSON 原始正文：source_sha256 为该文件原始字节
摘要（含空白），value_sha256 为叶值的规范 JSON UTF-8 摘要。规范序列化使用
ensure_ascii=False、sort_keys=True、分隔符逗号/冒号、禁止非有限数；字符串包含 JSON
引号。不是对裸字符串直接取摘要。该字节约定是本次适配明确化，尚待材料作者确认。

开发材料作者准备正文文件及 INTAKE.md 中的独立真值/授权/依赖契约后，可运行：

```sh
python docs/research/source-trust/convergence/material_adapter.py /path/to/development-manifest.json family-id /path/to/source.json
```

CLI 不回显原始正文，退出码 0 仅表示已登记开发材料的字节/契约一致；不证明真值语义、
作者独立性、模板独立性或实验授权。外部 holdout 家族不允许通过这个入口接入。
用户随后确认“那就是没有”；已结束目录查找，仓库清单继续保持 0/60。
[本地材料盘点](local-material-audit.json)记录了两工作树和历史清单，历史数据与测试夹具
不会自动转为新材料。没有待回复的路径请求。

执行探针只用于合成内容，沿用冻结 LoopbackReceiver 的限制。它不是通用真实材料
运行器，不提供批量 pilot 命令。材料真正接入后，还需确认其去标识化/合成属性、
任务指令到输出依赖的独立证据、真实任务完成回执以及完整支持的变换集合。

## 初始发现：当前面板对 H5 没有机制差异（已修复研究解释）

以下保留初始发现；用户要求修复后，已实施 [H5角色修订和适用性检查](H5_FIX.md)。
原始协议未覆盖重写；有效设计通过 protocol_amendment.py 载入。

冻结的 `security/source_trust_policy.py:effective_registry` 只把 MIXED 布局的
default_sensitive 改成 true；保留全部显式字段声明。当前生成器为每个叶提供显式
PUBLIC/SENSITIVE，适配器逐叶编译，结构标签两策略均为公开。对于此适配子集的
get_item/identity 路径，没有叶需要使用默认标签。因此 precision 与 conservative
的有效标签与阻断行为相同。合成集成测试也在 E0、SP p=1、PS p=1 观察到这一点。

这是可检查的代码路径性质和有限集成证据，**不是外部 holdout 上的 H5 实验结论**。
它提示：若完整首面板保持全叶显式声明和相同路径，不能期望该 conservative 默认值
改动产生 H5 所要求的 ASR AUC 降低。扩大样本数或增加重复无法制造缺失的机制差异。
观察到公开错标内容到达接收端也只证明该受控路径信任错误声明，不证明其他外发路径完整。

已实施的处理：保留原数值判据及预算，H5 在当前子集转为预设机制限制对照，
不再作为共同优越性主判据。H1–H3 保留原角色；不删字段、不换策略、不减少17项校正。
详情、协议差分和自动防回归约束见 [H5_FIX.md](H5_FIX.md)。
