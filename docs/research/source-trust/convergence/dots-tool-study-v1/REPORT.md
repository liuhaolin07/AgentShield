## 可写入论文的范围

可以作为工程实现说明写入：

> 在绑定来源、固定字段输出和固定本机接收器的合成开发工作流中，Dots模型成功发起工具请求并接收运行时结果。两次敏感字段外发在无防御对照中送达，在precision策略下被执行前机制阻断；两个正常任务在两策略下均完成。该验证仅覆盖此受限工作流。

本轮仅使用两个历史作者合成候选家族，来自同一业务模板。读取、投影和发送被封装为
单个受限工具，模型没有任意选择执行器或网络地址的权限；非法或偏离任务的请求会被框架拒绝，
这种拒绝不计为AgentShield阻断。模型只看到字段名与执行状态，实际字段值不发往模型API。

因此不能据此声称模型能力增强后权限仍不可突破、全部外发路径受控、H1–H5获支持，
或对来源错标、提示注入、隐式流及未覆盖真实任务具有鲁棒性。顺序固定、没有随机重复、
没有独立样本或第三方复跑，不计算总体置信区间或显著性。

下一步应围绕已声明边界补齐独立开发材料与语义/授权/依赖复核，并在冻结的开发计划中
加入所需真实任务及变换。H1–H5、E0/E1的54,720行、E3的3,600行及单列984行pilot预算保持不变；
本轮不抵扣这些预算，也不解除注册与外部保留材料门禁。
